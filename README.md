# История WhatsApp в ChatGPT

Поиск по выбранным чатам с указанием автора, времени, чата и идентификатора сообщения.
Например, вопрос «Когда договорились привезти оборудование?» может найти сообщение
«Привезём компрессор в пятницу» и показать соседние реплики.

## Импорт истории и автоматические обновления

Запустите панель на компьютере с запущенным Docker Desktop.

```sh
uv sync --locked --python 3.12 --extra semantic --extra audio
uv run --locked --inexact python import_ui.py
```

На [странице чатов](http://127.0.0.1:8081/) видны название, число сообщений
и год первого сохранённого сообщения. Нажмите на чат, чтобы прочитать переписку
и скачать вложения. Ранние сообщения подгружаются при прокрутке вверх.
После подключения кнопка «Добавить архив» открывает импорт TXT или ZIP из
WhatsApp на той же странице. Панель подставляет название из имени файла. Повторный экспорт
можно направить в существующий чат. В «Настройках импорта» можно указать своё
имя из файла. Реплики этого автора будут выделены как исходящие в этом чате.
Настройка ChatGPT открывается по кнопке
профиля. Чтобы сменить пользователя, выберите «Выйти» в профиле и введите
другой логин на экране входа.

Все входят через [одну страницу](http://127.0.0.1:8081/login) и попадают в свой
архив. На странице чатов нажмите «Подключить WhatsApp» и отсканируйте QR.
После подключения загрузите экспорт личного чата или группы. При единственном
совпадении по названию файла сервис добавляет новые сообщения в импортированный
чат после последней отметки времени в файле, затем проверяет его каждые пять минут.
Если система не смогла выбрать источник, рядом с архивом появляется возможность
выбрать чат из списка WhatsApp. Загруженная история доступна сразу.

Для проверки запустите панель с `WA_HISTORY_SYNC_INTERVAL_SECONDS=30`.
Новый интервал применяется и к существующим привязкам. Запуск без этой
переменной возвращает интервал в пять минут.

У администратора логин `admin` и пароль в файле `state/admin.key` с правами
владельца (при другом `WA_HISTORY_STATE` — в указанном каталоге). В профиле
администратора есть отдельный переход «Администрирование». В разделе
«Пользователи» можно создавать учётные записи, менять пароли и отключать доступ.
В разделах архива и источников можно выбрать пользователя, посмотреть его
переписку и вложения, выгрузить JSONL, исправить привязку или управлять
автообновлением. «Мои чаты» возвращает администратора к его личному архиву.

Группы добавляются в «Источники WhatsApp» после вступления подключённого
аккаунта в группу. Выбранная группа появляется в архиве этого пользователя.
Сервис собирает историю, которую видит это устройство,
проверяет новые сообщения каждые пять минут и периодически перечитывает доступную
историю. При необходимости более старую историю можно загрузить из экспорта.
Для обновлений должны работать панель и соответствующий экземпляр WAHA.

WAHA администратора привязан к `127.0.0.1:3031`. Для каждого именного
пользователя запускается отдельный контейнер WAHA с собственным локальным портом,
ключом и сессией. Архивы, индексы и файлы именных пользователей хранятся
в `state/accounts/<логин>/`, личный архив администратора — в `state/`.
Панель и MCP используют один корневой `WA_HISTORY_STATE` и одинаковую
настройку `WA_HISTORY_EMBED_MODEL`, когда нужна семантика. WAHA использует
неофициальное связанное устройство. Наличие сообщений и вложений для
автообновления зависит от того, что доступно связанному устройству.

### Экспериментальная догрузка с телефона из командной строки

Соберите локальный процесс догрузки (Go 1.26+ и системный компилятор для SQLite).
При другом `WA_HISTORY_STATE` передайте абсолютный путь к его папке в `-o`.

```sh
mkdir -m 700 -p state
go build -C peerworker -o ../state/wa-peer .
```

Для запуска нужна существующая отдельная привязка и ранее сохранённая выборка WAHA.
Сборщик запрашивает у основного телефона до 50 сообщений перед самым ранним
известным, повторяет запрос с новой датой и сохраняет прогресс после каждой
порции. Ограничения по числу порций или годам нет. Если телефон
прямо сообщил, что более ранней истории нет или он её не предоставляет,
сбор остановится и покажет причину. Отсутствие ответа не означает полноту.

Доступные вложения из порций сохраняются в том же архиве. Вложения больше
512 МБ и файлы, которые не удалось получить, остаются с соответствующим статусом.
Поиск по уже сохранённым порциям доступен сразу.

Для диагностического запуска с существующей отдельной привязкой можно
ограничить только этот запуск по числу порций:

```sh
uv run --locked --inexact python backfill.py \
  --device-store /absolute/private/device.sqlite3 --chat "Название чата" --pages 2
```

Не запускайте два процесса с одной базой привязки одновременно.

## Сбор через отдельный WAMVP

Этот режим подходит, если WAMVP уже развёрнут как отдельный экспортер.
Для одного рабочего архива выберите один автоматический источник.

Используется предоставленный WAMVP с WAHA/GOWS. В его веб-интерфейсе включите
режим «Выбранные группы», укажите дату, включите медиа и задайте расписание
«ежедневно в…». В исходной конфигурации WAMVP выбирает **все группы**, а подключение
сессии может немедленно запустить первый экспорт. До привязки выделите тестовую
группу или установите маску, которая совпадает только с её названием. Для личных
чатов в WAMVP есть общий переключатель. Дополнительный файл `--chat-list` позволяет
пропускать в локальный поисковый архив только выбранные идентификаторы личных чатов
или групп, но не меняет уже сделанную выгрузку WAMVP.

WAMVP сохраняет в `exports/` актуальный `messages.jsonl`, `status.json` и скачанные
оригиналы в `media/`. Для ежедневного режима можно подключить
`wamvp.daily.yml` вторым Compose-файлом рядом с исходным:

```sh
docker compose -f docker-compose.yml -f /path/to/whatsapp-history/wamvp.daily.yml up -d --build
```

Для запроса истории за прошлые годы укажите `HISTORY_DAYS=3650` (или другой
нужный период в днях) в локальном `.env` WAMVP **до новой привязки** и задайте
в его интерфейсе дату, с которой нужно собирать сообщения. Прежний `.env`
обычно содержит `HISTORY_DAYS=365` и переопределяет значение по умолчанию из
Compose. Уже привязанной сессии для применения нового запроса понадобится
перепривязка. Флаг задаёт запрашиваемую глубину, WhatsApp всё равно сам решает,
что отдать связанному устройству.

Первый запуск опрашивает доступную историю с выбранной даты. Последующие опросы
обновляют свежий диапазон с перекрытием и примерно раз в неделю повторяют полный
проход, чтобы подобрать поздно поступившую историю. Запрошенная дата не гарантирует
полноту: WhatsApp может отдать связанной сессии только часть старых сообщений
и вложений. В интерфейсе WAMVP и через `archive_status` виден фактический диапазон.
Историю, которой нет в автоматической выгрузке, можно дополнить экспортом с телефона.

## Локальный архив и поиск

Из каталога этого компонента:

```sh
uv sync --locked --python 3.12 --extra semantic --extra audio
export WA_HISTORY_STATE=/absolute/private/whatsapp-index
export WA_HISTORY_EMBED_MODEL=/absolute/path/to/local/sentence-transformer-snapshot
uv run --locked --inexact python sync_archive.py /absolute/path/to/WAMVP/exports \
  --watch 60 --whisper-model /absolute/path/to/local/faster-whisper-snapshot
```

Процесс проверяет публикацию WAMVP раз в минуту, но обращается только к локальной
выгрузке. При изменении снимка он прочитывает его для сверки состава чатов и
обновляет поисковый индекс только для новых или изменившихся сообщений. Для
однократной загрузки опустите `--watch`. Если убрать чат из WAMVP и пересобрать
снимок, его автоматически полученные сообщения пропадут из результатов после
следующего успешного импорта. Добавленные вручную сообщения остаются доступны.
Старые записи и оригиналы сохраняются на диске. Удалённые у всех сообщения скрываются
из поиска, если соответствующее событие дошло до WAMVP.

Тексты, подписи, имена вложений и расшифровки индексируются в SQLite FTS5 и
эмбеддингах. Векторы хранятся в той же SQLite. На небольшом пилоте они ранжируются
точным сравнением, поэтому отдельная векторная БД не нужна. Для поиска по смыслу
используйте локальный каталог модели `paraphrase-multilingual-MiniLM-L12-v2`.
Без `WA_HISTORY_EMBED_MODEL` на пустом индексе остаётся текстовый поиск.
При импорте и поиске задавайте одну модель. При переходе на другую модель пересоберите векторы.

Фотографии, голосовые, видео и документы копируются в приватное хранилище
оригиналов. `--whisper-model` включает локальную расшифровку доступного аудио.
Хеш позволяет переиспользовать расшифровку одного и того же оригинала. OCR и
поиск внутри PDF, Office и картинок пока отсутствуют. Выдача поиска содержит
метаданные вложений и фрагменты расшифровок. Сохранённое изображение можно
запросить отдельно через MCP.

### OpenAI Embeddings

Для облачной VM можно использовать `text-embedding-3-small` с 512 измерениями.
Установите зависимости в отдельном окружении для облачного режима.

```sh
uv sync --locked --python 3.12 --extra openai-embeddings
export WA_HISTORY_EMBED_PROVIDER=openai
```

Задайте `OPENAI_API_KEY` как секрет окружения панели и MCP. Оба процесса
должны использовать этот режим. Панель сохраняет сообщения и индекс BM25
сразу, затем рассчитывает векторы пакетами в фоне. При ошибке API остаётся
поиск по словам. Сервис передаёт OpenAI текст для индексации и поисковые
запросы. Оригиналы вложений хранятся в архиве.

Для переноса существующего архива остановите панель и MCP. Запустите
`uv run --locked --inexact python sync_archive.py --reindex-embeddings`
с тем же секретом и `WA_HISTORY_STATE`, указывающим на каталог конкретного
архива. Для именованного пользователя это `state/accounts/<логин>/`.
Команда ставит сообщения в очередь для новой модели. История, вложения
и индекс BM25 сохраняются. После запуска панели с корневым `WA_HISTORY_STATE`
она обработает очередь. Для нового архива достаточно запустить панель
и MCP с выбранным провайдером.

## Добавить историю вручную

Запустите панель на том же `WA_HISTORY_STATE` и с той же моделью поиска:

```sh
uv run --locked --inexact python import_ui.py
```

1. На телефоне откройте нужный чат в WhatsApp и выберите «Экспорт чата»,
   с медиа или без них. Сохраните оригинальный UTF-8 TXT или ZIP.
2. На компьютере откройте [панель архива](http://127.0.0.1:8081), выберите файл
   и создайте чат либо явно укажите существующий. Допустимы ZIP до 10 ГиБ
   и TXT до 64 МиБ. При необходимости укажите порядок дня и месяца и часовой пояс самой
   переписки. Панель покажет фактические даты и число импортированных сообщений.
3. В разделе «Архив и экспорт» можно выбрать чат и год по UTC или оставить год
   пустым, чтобы скачать весь собранный период в JSONL. JSONL содержит сообщения
   и метаданные вложений. Оригиналы из ZIP сохраняются в `state/blobs`
   (или в каталоге, указанном в `WA_HISTORY_STATE`). Вложения с однозначным
   именем связываются с сообщением, если это имя присутствует в тексте выгрузки.
   Остальные файлы тоже сохраняются, панель сообщает их количество.

При больших загрузках серверу нужно место для временного ZIP и распакованных
вложений. ZIP может содержать до 100 000 файлов общим размером до 32 ГиБ после
распаковки. Если панель стоит за Nginx, примените к POST-маршрутам `/import`
и `/admin/import` настройки:

```nginx
client_max_body_size 11g;
client_body_timeout 180s;
proxy_http_version 1.1;
proxy_request_buffering off;
proxy_read_timeout 3600s;
```

Повторный импорт одного и того же текста в тот же чат не создаёт дублей.
У телефонного TXT обычно нет идентификаторов WhatsApp. При перекрытии
по датам с WAMVP одинаковые реплики с двух источников могут сохраниться отдельно.
Добавленные вручную сообщения сразу доступны в существующих инструментах MCP.

Удаление чата из архива доступно в открытой переписке, а администратору также
в разделе «Архив и экспорт» выбранного пользователя. После подтверждения
история пропадает из архива и поиска, автообновление выключается, а файлы,
которые используются только этим чатом, освобождают место на сервере.
Сам чат в WhatsApp остаётся.

Для расшифровки импортированных голосовых без запущенного WAMVP:

```sh
uv run --locked --inexact python sync_archive.py \
  --whisper-model /absolute/path/to/local/faster-whisper-snapshot
```

## MCP и ChatGPT

```sh
uv run --locked --inexact python mcp_server.py --http
```

MCP Streamable HTTP слушает `127.0.0.1:8079/mcp`. Без `--http` этот же процесс
работает через stdio. `plugin.json` и `mcp.json` описывают локальное подключение
для совместимого desktop-клиента. Перед запуском задайте те же `WA_HISTORY_STATE`
и `WA_HISTORY_EMBED_MODEL`, что использовались при импорте.

- `search_messages` возвращает фрагменты с автором, чатом и временем.
  Можно ограничить выборку названием чата и диапазоном дат.
- `get_image` возвращает один сохранённый JPEG, PNG или WebP до 8 МиБ.
  Передайте чат, точное время и имя вложения из поиска. Если известен автор,
  передайте и его.
- `get_document` читает текст выбранного PDF, DOCX, XLSX или TXT до 12 МиБ.
  Передайте те же данные из поиска. PDF читается по текстовому слою, до 30 страниц,
  извлечённый фрагмент ограничен 12 000 символов.
- `get_context` возвращает несколько сообщений до и после результата в том
  же чате. Передайте название чата, точное время и автора из результата поиска.
  Если сообщение ссылается на доступную реплику, возвращаются её чат, автор и время.
- `archive_status` показывает дату снимка и фактическую глубину истории.

Состояние сервера видно в профиле. OAuth с PKCE выдаёт токен только для
личного архива. Пользователь входит из ChatGPT с логином и паролем от панели.
Администратор задаёт отдельный пароль ChatGPT и входит с логином `admin`.
Отключение пользователя и смена пароля отзывают текущие подключения.
Локальный режим stdio использует архив администратора.

Для ChatGPT Web задайте одинаковый `WA_HISTORY_MCP_ORIGIN=https://mcp.example.com`
для панели и HTTP MCP. HTTPS-прокси должен направлять на порт 8079 пути MCP,
OAuth discovery, регистрацию, получение токена и страницу входа. В ChatGPT
добавьте адрес `https://mcp.example.com/mcp` и выберите OAuth. При подключении
через [Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)
страница входа OAuth всё равно должна быть доступна клиенту. Сервис передаёт
найденные фрагменты и метаданные. [Инструкция подключения](https://developers.openai.com/plugins/deploy/connect-chatgpt).

Чтобы открыть саму панель с телефона, можно использовать отдельный приватный
HTTPS-прокси с аутентификацией к порту 8081. Укажите его адрес в
`WA_HISTORY_ADMIN_ORIGIN` и сохраняйте Host и HTTPS-схему в запросах к панели.
Вход администратора защищён отдельным ключом, вход пользователя — его паролем.

## Проверка

```sh
uv run --locked --inexact python -m unittest -v
```

Тест охватывает начальную и повторную загрузку, изменение и удаление сообщения,
исключение чата, хранение оригинала и MCP-вызовы. Для ручного импорта проверяются
TXT/ZIP за прошлые годы, сохранение вложений, добавление в существующий чат,
повторная синхронизация WAMVP и выгрузка выбранного года. С `WA_HISTORY_EMBED_MODEL`
добавляется реальный тест семантического поиска. С `TEST_WHISPER_MODEL` на
macOS тест генерирует синтетическое голосовое и ищет его по расшифровке.
Живая привязка WhatsApp, качество исторического покрытия и установка плагина
в конкретный ChatGPT workspace требуют отдельных проверок.
